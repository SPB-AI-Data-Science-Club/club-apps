Club Jeopardy

Set up the game

Pick a question set and add your teams. Teams take turns picking a tile; you (the host) award points after each answer. Everything runs offline in this one file, so it works on a projector with no internet.

Host controls: click a tile to open the clue, Space reveals the answer, then click the team that got it (or "No one").  Esc closes a clue.
To add a set for a meeting, drop a .json file next to this page and use "Load custom set", or ask Claude Code to add one.
