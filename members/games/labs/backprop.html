Watch a Network Learn

This is a small neural network with one hidden layer. Every epoch it runs a forward pass, measures how wrong it is, then uses backpropagation to send that error backward and nudge each weight. Hit run and watch the loss curve slide down while the decision boundary bends to separate the two colors. Crank the learning rate too high and you will see the loss bounce instead of settle, exactly like Day 2 warned.
